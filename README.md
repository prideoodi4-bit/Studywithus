# ادرس ويانا 📚

1. افتح https://t.me/BotFather وأرسل /newbot. اختَر اسم «ادرس ويانا» ويوزر متاح ينتهي بـ bot.
2. فك الضغط. للتشغيل على جهاز عليه Python 3.9 أو أحدث، افتح الطرفية داخل مجلد الملفات. على Linux أو macOS أو Termux نفّذ الأوامر التالية، وعند الطلب الصق التوكن محلياً:
```bash
read -rsp 'Bot token: ' BOT_TOKEN
export BOT_TOKEN
python3 bot.py
```
3. للتشغيل المستمر ارفع Dockerfile وbot.py إلى خدمة تشغّل Docker كعامل دائم، واضبط السر BOT_TOKEN واربط قرصاً دائماً على /data. شغّل نسخة واحدة فقط. على جهازك المحلي يجب أن يبقى البرنامج والإنترنت شغالين. البوت يستعمل long polling.
4. ضيف البوت مشرف بسوبركروب وفعّل حذف الرسائل وتقييد الأعضاء وتثبيت الرسائل. اكتب /setup من حساب مشرف ظاهر باسمه. الأمر يعيد تثبيت اللوحة عند الحاجة.
5. الطالب يكتب /session ويختار ساعة أو ساعة ونص أو ساعتين، ويرد على سؤال البوت بموضوعه. يبدأ الوقت عند إرسال الموضوع. عند النهاية يسجل الطالب إجابته بزر خلصت أو بعدني. عند التحديث احتفظ بقاعدة البيانات.
6. أول رسالة من المشارك تنحذف ويظهر تنبيه، وبعدها ينكتم العضو العادي إلى نهاية ساعته. في آخر 65 ثانية يكتفي البوت بالحذف حتى لا يتحول الكتم القصير إلى دائم. المشرف والمالك المشاركان باسميهما يتلقّيان تنبيهاً كتابياً فقط بكل رسالة. يُكتفى بالحذف لأصحاب القيود السابقة بعد التنبيه. بقية الطلاب يكدرون يحچون عادي.
7. بالخاص اضغط Start حتى يطلع زر قناة https://t.me/iwillsleep . ما يحتاج البوت إدارة بالقناة.

تحديث السشنات: يعرض /session ساعتين مضبوطتين بتوقيت بغداد تراعيان الحد الأدنى، وخيار كتابة مدة من 60 إلى 1440 دقيقة أو وقت نهاية HH:MM، وخيار الانضمام لنفس موضوع زميل. للطالب المنضم ساعة كاملة على الأقل. الأسماء قابلة للضغط، ويُنشر إعلان عند نجاح الكتم. ملصق الكتاب يُرسَل بعد تأكيد إنجاز الموضوع. عند النشر حدّث جميع الملفات بما فيها finished.webp.
